01 — Logo

The mark & wordmark

The audena mark is two rising petals in periwinkle blue — a forward chevron suggesting momentum and lift. It pairs with the lowercase serif wordmark. Give it room; never crowd or recolor it.

Lockup · reversed
Mark · charcoal
Lockup · on wash

Do

Keep clear space of at least the mark's height on all sides.

Use the charcoal mark on light, the blue-on-charcoal lockup on dark.

Don't

Recolor the wordmark, add effects, or stretch the lockup.

Place the mark on a busy photo without a solid or washed backdrop.

06 — Tokens

Copy-paste foundation

Drop these variables into the top of any new page to inherit the full system. Fonts live in /fonts, logos in /assets.

/* audena design tokens */ :root { /* core */ --ink: #323432; /* dark surface + text */ --ink-deep: #1f2120; /* hover / pressed */ --paper: #f6f3ee; /* warm off-white */ --white: #ffffff; /* accent + semantic */ --accent: #678dc6; /* periwinkle */ --accent-press: #5876b3; --positive: #2a9d6e; /* text on light */ --t-strong: #2a2c2a; --t-body: #5a5c5a; --t-faint: #888a88; /* hairlines */ --hair: #e0e0e0; /* signature wash */ --wash: linear-gradient(135deg, rgba(190,210,240,.35), rgba(255,230,210,.35)); /* radii */ --r-pill: 999px; --r-card: 14px; --r-lg: 18px; } /* type */ --font-display: "P22Mackinac", serif; /* 400, -0.03em */ --font-ui: "Inter", system-ui, sans-serif; --font-mono: "Inter", system-ui, sans-serif; /* labels */
